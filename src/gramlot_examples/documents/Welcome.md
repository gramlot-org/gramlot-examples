# Document workspace

Open a document in the tree, edit its text and try Undo or Revert.

Changes stay in this browser tab. **Save requires Remote Edit**, enabled by the host.
The gallery serves a temporary copy of these examples; restarting the gallery restores them.

- `customer.json`: structured data
- `page.html`: HTML source and preview
- `notes.py`: Python text (not executed)
- `report.typ`: a Typst document
