# Value rows

> **What you learn** — Use the same report over records stored as value Bags.

The same report uses `rowMode="values"`: each record is a Bag held in a node value. Charts, grid search, configuration and reload behavior remain the same. Compare Attribute rows. This is an explicitly named qualification fixture, separate from the live sales provider. Shared implementation: `gramlot_examples/base/chart_report.py`.
