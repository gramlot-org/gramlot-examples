# Monthly snapshots

> **What you learn**
> Use the shared chart configurator to show prepared monthly snapshots.

The example builds twelve months of sample rows in a Bag. Each row contains a date, region, revenue, margin and rank. These are prepared demonstration values, not the live database report.

`timeField` identifies the date and `timeStep="month"` selects a monthly frame. Move the slider or press Play to change the visible frame. The chart selects rows; it does not calculate monthly aggregates.

Open Chart settings to choose measures or change the period. Turning time filtering off restores all rows. For uPlot, select a line chart and the numeric rank as the category.

Data and chart configuration are Bags: changing either updates the chart. Detach Example, Explanation or Code to compare them side by side without restarting the example.
