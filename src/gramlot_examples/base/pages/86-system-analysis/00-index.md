# Live examples

Two larger examples show live measurements flowing into Data Bags and shared
charts and grids. They are imported development examples for detailed review.

- **System monitor:** Python collects CPU, memory, process, disk and network data
  with psutil. PageStore and WebSocket deliver it to movable dashboard panels.
- **Microphone analysis:** the browser captures microphone samples on demand and
  updates waveform and spectrum charts. Audio stays in the browser.

Open Explanation for the walkthrough and Code for the Python declarations.
The system monitor measures the machine running the local server; microphone
analysis uses the device running the browser. No Asqueel database is needed.
