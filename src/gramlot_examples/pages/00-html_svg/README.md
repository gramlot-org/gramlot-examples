# Fundamentals

Learn how Gramlot turns declarations into a page, using familiar HTML elements.

- **Hello, Gramlot!**: create a heading and a paragraph in Source.
- **Data and bindings**: store values in Data and connect them to HTML text, input values and attributes with `^`.
- **Children and styles**: nest elements and declare styles such as `color="red"` without writing a stylesheet.
- **Labels and boxes**: use `lbl` and `box_*` on HTML; the same mechanism will accompany Gramlot components.
- **HTML and SVG**: build a small drawing with the same declaration model.

Finish by opening **Inspector** in the gallery rail on **Data and bindings**.
Compare the changing values in **Data** with the elements and binding declarations
in **Source**. Data holds the current values; Source describes the interface.

This section needs only named Data entries and `^` bindings. Path scoping,
expressions and other binding forms belong to later lessons.
