# Learn to arrange a workspace

A useful screen needs room for the task in front of you, while keeping other tools within reach. In these lessons you will build that idea one step at a time: divide the space, put one layout inside another, tuck panels away, and move between tasks without losing your edits.

You can start by playing with a page. Its **Explanation** tab tells you what to try and what the result means. Open **Code** when you want to connect that behavior to Python or JavaScript. There is no need to understand every declaration before your first experiment.

## Navigation

In the gallery, expand **Containers → border** to find the six borderContainer lessons. Select **border** itself for a general introduction and a small five-region layout. Tabs, Stack, Dialog, Floating and groupBox remain directly under Containers and layout. The border branch loads its children only when expanded.

## A route through the lessons

Start with **Border regions and splitters**. Learn what a region is and how the center makes room when you resize a side panel. Continue with **Nested borders** to give part of a page its own layout, then **Rounded borders** to combine that layout with calendars and other popups.

**Drawers** shows how to put tools away without losing their values. Its **Guide** handle opens a step-by-step demonstration, with optional voice. Once you are comfortable, **Nested regions playground** gives you a larger workspace to explore.

**Border events** explains how your page can hear about a change and react. **Tabs** introduces switching between panels and the different meaning of closing one. Finally, **Demo carousel** uses a slider to browse a stack of pages, with a short pause before opening the chosen page at full size.

The same lessons run in the Python, JavaScript and offline galleries. Code shows the language of the gallery you are using.

## Compare appearances

**Mela: desktop and touch** brings a toolbar, hierarchical menu, fields, dialog and floating window together. Choose Mela in Gallery Settings and compare Light/Dark or resize to phone width.


## Windows and groups

**Dialog: modal editing** makes the background unavailable until the dialog closes, even while collapsed. **Floating: keep the page usable** uses the same form and frame composition without blocking the background. Edit, move, resize, maximize and reopen the windows to see retained Data.

**groupBox: group fields and copy Data** groups related fields under one label and datapath. Its copy command exports only that group, preserving types with TYTX.

## Live pages on a tray

**Gallery tray** starts empty. Pick a lesson in its toolbar and add it as an independent live card at reduced zoom. This complements **Tray workspace**, which composes widgets directly in the same page and demonstrates layout snapshots.
