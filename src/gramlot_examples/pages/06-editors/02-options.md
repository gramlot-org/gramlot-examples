# Editor options

**Try this:** Open the editor's Options drawer and change wrapping or font size. The draft remains; changing Language and sample intentionally replaces it.

Open the Options drawer to change language, indentation, wrapping, line numbers, font and editing aids. Configuration preserves undo and selection. Each instance owns its settings in Data.

Type to update the bound draft. Read-only keeps selection, copy and search available. Disabled prevents editing and focus. Save is explicit and copies to a Data snapshot in this example. External document replacement resets undo. The default indentation is four spaces.

Choose **Language and sample** to load a matching snippet and change the editor language. All ten supported languages are represented. Selection replaces the current draft and resets its undo baseline; the saved snapshot stays unchanged. In the options example the drawer language field shares the same Data selection.

**Sample data:** `02-options_data.tytx` supplies the initial Bag in Python and JavaScript. Interface defaults initialize UI state; bindings handle later edits.
