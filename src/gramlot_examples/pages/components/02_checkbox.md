# 02 · Checkbox and labelbox

Two checkboxes share one boolean preference. Click either caption, then disable both using the State checkbox.

**Uses:** the first 0.3 input components, shared labelbox, Source, Data and bindings. No endpoints or validation engine.

<details>
<summary>More detail</summary>

`lbl` names the field; `label` is the caption beside the checkbox. The stored value is `True`/`False` in Python and `true`/`false` in JavaScript.

**Try it:** click either checkbox and inspect the shared boolean in Data. For layout variants, use Settings (⚙) in the gallery footer.

</details>
