# AI assistants

These lessons call large language models from the Python server. The chat talks
with an Anthropic model and draws images with OpenAI. The visual editor gains a
chat that edits its Source in validated steps.

The API keys stay in the server environment. The browser receives only text,
Source and Data. When the server has no keys, each lesson says that AI examples
are not configured on this server. On the public gallery each page session has
a limit of messages and images.
