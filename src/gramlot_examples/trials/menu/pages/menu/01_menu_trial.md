# 6. Complete document workspace

The same Python method declares a popup and a permanent toolbar. A prepared JS
collection registers command defaults; the central frame content handles their
five-field messages using named Logic methods and Data writes.

Try Save in both presentations, Details, disabled/hidden bindings, the Export
resolver, fixed/elastic spacers, an embedded input and a nested permanent bar.
The two extra Save actions demonstrate confirmation and parameter capture before
a delay. Resolver error deliberately fails the endpoint; turn it off to recover.

This is a provisional Python integration trial, not a stable menu API or release.
It uses the existing extra-catalog mechanism; common cross-host lessons are unchanged.
