# Uploader

Explore file uploads with metadata, record attachments and editable images.

Uploads need a server that accepts them. The Python Uvicorn server (`gramlot uvicorn gallery`) and the serverless export accept uploads. The hosted public galleries, the Kajenn server and the Node.js/Bun server do not: there **Upload** marks each file "Upload is unavailable in this environment". Each lesson states which case applies; choosing files and editing the queue work in both.
