# Selection trial · JSONL / HTTP

JSONL is the selected full-selection path for this lesson and the floating invoice
Grid. TYTX iterators preserve Dates and Decimals while the browser builds an
isolated Bag. Only a valid completion receipt publishes the new selection.
Cancelled, failed or superseded requests preserve the last successful Bag.

Choose up to 100,000 invoice rows. Query measures execution and complete fetch;
server encoding measures TYTX/JSON line encoding. Body reception overlaps client
decoding and insertion and is not isolated network time. Ready ends before Data
publication and rendering. Search remains local and excludes debounce and paint.

The former JSON HTTP and complete WebSocket response lessons are retired. Their
100,000-row comparison remains historical evidence in GC-375. cachedFetch remains
a separate Asqueel-only page with server search/sort and a small browser window.
This JSONL route is available in the local Kajenn Base and release preview hosts.
