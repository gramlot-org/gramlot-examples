# bun Hello World

Run `npm run start:bun` from the application directory after installing the local artifact graph.
The installed command is `gramlot-hello-bun`.
`HOST` defaults to `127.0.0.1`; `PORT` defaults to `8080`.
The launcher uses the reusable `gramlot-nodejs` adapter and the same installed JS Page.
No database is initialized. Floating upstream installation remains pending source consolidation.
