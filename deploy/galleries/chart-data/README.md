# Geography resources of the chart reports

Copied into the Python gallery image and read by SalesCharts and SalesGeography.

- `states.geojson`: Australian states and territories, from Natural Earth
  (public domain).
- `sal/<STATE>.geojson`: Suburbs and Localities (SAL) 2021, one file per state,
  from the Australian Bureau of Statistics (ASGS Edition 3), licensed under
  Creative Commons Attribution 4.0 International. Source: Australian Bureau of
  Statistics.
